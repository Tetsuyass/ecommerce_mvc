# Installation : 

## DB : 

Copier le script SQL dans votre gestionnaire de base de données.
Puis changer les identifiants dans le config.ini par les votres et votre DB.

## Lancement du projet

Si vous utiliser WAMPP server (comme un être humain normalement constitué). Lancer les services et vérifiez que la connexion à la base de données marche bien.
Lancez le frontend avec la commande 

```
npm run dev
```

depuis le dossier frontend.

Et lancer le backend PHP avec la commande

```
php -S localhost:8080
```

Ensuite accéder au lien du front et votre site fonctionne.
